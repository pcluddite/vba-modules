# vba-modules

Various VBA modules to ease the cumbersome task of writing VBA macros. The modules are as follows:
* **SheetEx.bas** - ease manipulation of sheets and ranges
* **PowerSheet.bas** - powerful functions for manipulating Excel data utilizing a hidden temporary sheet
* **Win32File.bas** - a set of functions based on the Windows API to manage the file system
* **SqlHelper.bas** - functions for creating SQL statements
